# 1. 반응형 레이아웃 (Figma)

Figma 연결 확인하고, 내 포트폴리오 사이트(my-new-portfolio-ling-d2f5.vercel.app)를 기준으로 Mobile/iPad/Desktop 반응형 레이아웃 3개를 만들어줘. 실제 클릭 가능하고 수정 가능한 Figma 파일이어야 하고, 내용은 사이트랑 완전히 똑같아야 해.

이후 발견한 문제를 하나씩 알려주고 매번 "사이트랑 똑같이" 1:1로 맞춰달라고 요청, 수정 후 결과 확인하며 반복 진행:

1. 폰트가 일치하지 않는 부분이 있어
2. 스크립트/영상 섹션 이미지가 안 나와
3. 게임 섹션 iPad 뷰에서 빈 공간이 생겨
4. 지금 각 섹션 색이 콘텐츠 끝나는 지점부터 흰색으로 바뀌어

→ 중국어 한자 제목이 깨지는 문제, 이탤릭 기울기 방향, 아이패드 게임 패널 3열 그리드 빈틈, 섹션 배경이 콘텐츠 아래에서 끊기는 문제까지 발견한 버그들을 수정 요청

## 추후 업데이트 (작품집 사이트 "과제" 탭 내용 변경 반영)

작품집 사이트에 과제가 추가/수정될 때마다 Figma 속 Assignments 페이지(Desktop/iPad/Mobile)도 실제 사이트와 1:1로 맞춰 업데이트:

- "내 작품집 사이트에 올린 링크를 다른 사람이 못 연다, 원인을 확인하고 해결 방법을 알려줘" → Figma 파일 공유 설정이 "Anyone with the link"로 되어 있지 않아서 발생한 문제로 진단, 해결 방법 안내
- "현재 정면의 Ling + 학교 정보가 좌측 하단에 있어야 하는데 지금 좌측 상단이다" → flex 레이아웃에서 단일 자식 요소가 space-between으로 인해 상단에 붙는 버그를 발견하고 수정
- "지금 작업을 figma에 가서 해줘" / "변경사항은 그대로 두고 業務 반영" 반복 요청으로 Desktop 2단 컬럼 배치(실제 사이트의 컬럼 밸런싱 로직까지 재현), iPad/Mobile 단일 컬럼 순서를 실제 사이트와 대조하며 업데이트
- 작품집 사이트가 7주차 → 8주차로 과제 번호가 바뀌고, Skill Creation 4개 항목이 비교형 2개 항목으로, 프롬프트 구조화 4주차 항목이 5주차로 병합되는 등 큰 구조 변경이 있었을 때: "내 작품집 사이트가 업데이트됐다, 과제 탭 기준으로 레이아웃 3종을 업데이트해줘" → 실제 사이트를 Desktop/iPad/Mobile 각 너비로 직접 열어 컬럼 분포·순서·문구를 모두 대조한 뒤 Figma에 반영
