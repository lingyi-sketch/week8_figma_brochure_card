# 2. 포트폴리오 브로슈어 (A4, 1장)

포트폴리오 사이트를 중심으로 한 1장짜리 브로슈어 PDF도 Figma로 만들어줘. 사이트의 글/이미지를 재사용하고, 디자인은 외부 레퍼런스를 참고해도 좋아. 먼저 미리보기부터 보여줘 (크레딧 낭비하기 전에 확인하고 싶어).

→ Wes Anderson풍 대칭 레이아웃 시안 제안 → "원래 디자인을 그대로 유지하고, 여백 문제만 고쳐서 다시 미리보기 해줘. 새로운 블록(필름 크레딧 스타일 문구 등)은 추가하지 말고, 기존 brochure_figma.pdf만 가지고 수정해줘" → 기존 요소를 확대/재배치해서 하단 여백 문제 해결, Figma에서 직접 제작 완료

## 세부 수정 요청

- "宣传册 Selected Works 중 비디오 카드가 스크립트/게임 카드보다 살짝 길다, 수정해줘" → 세 카드의 auto-layout 세로 크기(HUG→FIXED) 통일
- "宣传册 수정 이후 하단 검은색 '엔딩 크레딧' 색상 띠가 없어졌다, 그리고 아래 세 군데를 참고 이미지대로 수정해줘" (EMAIL/SITE 라벨, PORTFOLIO BROCHURE ① 위치, CUT 04 — AUTUMN 위치) → 본문 블록 간격을 좁혀 7번째 Weekly Log 줄을 추가했을 때 머리말+본문+꼬리말 합계가 A4 높이를 넘어 하단 검은 띠가 캔버스 밖으로 밀려난 것으로 진단, 간격 재조정으로 복구. 이메일/사이트 라벨을 "SCRIPTS WRITTEN"과 같은 스탯 라벨 스타일로 변경, 로고와 사진 사이 빈 공간에 "PORTFOLIO BROCHURE ①" 킥커 라벨 추가, 사진 우상단에 "CUT 04 — AUTUMN" 캡션 추가
- "참고 PDF 버전대로 PORTFOLIO BROCHURE①/CUT 04/EMAIL·SITE 세 부분만 다시 조정해줘, 나머지는 그대로" → 레퍼런스 PDF 분석 후 킥커 라벨을 우측 정렬 2줄로 변경, SITE 주소를 2줄로 줄바꿈
- "문제 없으면 수정된 거 작품집 사이트 8주차 과제에 다시 업로드해줘" → 관리자 패널에서 기존 PDF 파일 교체
- Weekly Log를 작품집 사이트 "과제" 탭 최신 내용에 맞춰 업데이트(8주차 신규 추가, 7주차 Skill Creation 비교형으로 교체, 5주차 통합 등)
