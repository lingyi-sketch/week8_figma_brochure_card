# 3. 명함 디자인 (로고·색상·워터마크)

로고("링이")는 손글씨/예술적인 느낌의 폰트로, 사이트 팔레트 색을 활용해서 만들어줘(색 섞거나 그라데이션도 가능). 명함에는 이름·소속·이메일·전화번호·사이트 주소 들어가야 해. 외부 디자인 레퍼런스 참고해도 좋고, 크레딧 아끼려면 먼저 미리보기부터 보여줘도 돼.

명함 색상은 코코아+와인색(A안) 기반으로, 민트+연핑크를 포인트로 쓴 디자인(B안) 둘 다 보여줘 → 모서리 절개 디자인은 빼고 점 포인트로 재설계 → 기존 원형 테두리 장식에 민트·핑크 동심 아크 추가 → Figma에서 실제 제작

## 한자 워터마크 반복 작업

- "반투명 워터마크로 크게 깔아줘, 글씨체도 손글씨/붓글씨 느낌으로" / "글자를 좀 더 길쭉하게, 서예 느낌 강하게 해줘" / "직접 쓴 사진을 그대로 써서 합치고 싶어 — Figma 크레딧 드나?"(업로드만 하면 무료라고 답변) → 사용자가 직접 올린 서예 사진을 흰 배경 + Multiply 블렌드 기법으로 명함 배경에 완전히 자연스럽게 합성 (사진이 webp 형식이라 업로드가 실패했던 원인도 함께 진단·해결)
- "이 글자 색을 검은색으로 바꿔줘" → 이미지 채도를 낮추고 대비를 올려 흑백 톤으로 조정
- "명함 배경 색을 회색으로 바꿔줘" → "다시 원래대로 돌려줘" → 배경색 원복
- "명함 디자인을 전체적으로 밝고 눈에 띄는 색으로, 외부 명함 디자인 참고해서 바꿔줘" → "채도가 너무 높다, 낮춰줘" → "색은 연핑크+민트+연한 커피색으로, 레이아웃은 기존 그대로" → 최종적으로 원래 사이트 팔레트(코코아/마룬 + 민트·핑크 포인트)로 복귀, "相灵昳" 세 글자를 가로로 배치
- "相灵昳 세 글자가 크기가 안 맞아 보인다, 눈대중으로 맞춰줘" → 실제 렌더링된 글자의 잉크 영역을 픽셀 단위로 측정해 크기 보정 (昳 글자가 원본 이미지 내 여백이 많아 실제보다 작게 보이는 문제를 발견해 별도 보정)
- "정면과 캔버스의 흰 배경이 안 맞는 것 같다" → 카드 프레임이 상위 섹션 안에서 16px/14px 밀려 있어 섹션의 흰색 배경이 카드 크림색과 다르게 노출되던 정렬 버그를 발견해 카드를 좌상단 (0,0)으로 정렬
- "相灵昳 색을 뒷면 '링이' 로고와 같은 깊이로 짙게 해줘" → 워터마크 불투명도를 0.24 → 1.0으로 올려 로고와 동일한 톤으로 통일
- "뒷면 '링이' 로고가 검은색이라 튄다, 연락처 정보와 같은 색으로 바꿔줘" → Figma COLOR 블렌드 모드로는 순수 검정 잉크를 재채색할 수 없다는 점(명도 0에서는 색상 정보가 보이지 않음)을 확인하고, 픽셀 단위 밝기 기반 듀오톤(흰색→커피색 보간) 방식으로 직접 재채색
