## 과제 개요

1. **반응형 레이아웃 3종** — Desktop(1440px) / iPad(834px) / Mobile(390px) 각각에 프로필·스크립트·영상·게임·과제 5개 페이지를 실제 사이트 내용과 동일하게 재구성하고, 페이지 간 클릭 이동(프로토타입)까지 연결
2. **포트폴리오 브로슈어 (A4, 1장)** — Figma에서 직접(네이티브로) 제작한 PDF. 사이트의 색상·타이포그래피 시스템을 그대로 적용
3. **명함 디자인 (앞/뒤)** — 사이트 팔레트(코코아·마룬 + 민트·핑크 포인트)를 기반으로 한 배색, 손글씨 로고, "相灵昳" 한자 워터마크
4. **로고 / 워터마크** — "링이"는 AI로 생성한 손글씨(서예) 스타일 로고, 명함의 "相灵昳" 세 글자는 직접 쓴 서예 사진을 배경과 완전히 자연스럽게(이음새 없이) 합성
